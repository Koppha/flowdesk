# Slide 1 — Introducing the System

**Advance → Clearance System**
A single platform to request, approve, and clear staff advances (cash & travel).

- Replaces manual/paper advance forms with one digital workflow
- Covers: Travel advances, Salary advances, Loans
- Built-in approval workflow engine — routes each request through the correct approvers based on the requester's department/section (e.g. Countersign → Manager/HOD → HR → Finance)
- Role-based Inbox: every approver only sees requests waiting on *them*
- Real-time status tracking from submission to payment (SUBMITTED → COUNTERSIGNED → HR Review → APPROVED → PAID)
- Email notifications keep requesters informed at each step

---

# Slide 2 — Why It Matters

- **Visibility:** requester always knows where their request is in the chain
- **Control:** approval routing is configured centrally (Workflow Builder) — no more "who approves this?" guesswork
- **Accountability:** every approval/rejection is logged against the person and step
- **Speed:** auto-calculated amounts (rates by staff tier, days/meals), no manual computation errors
- **Flexibility:** supports temporary/once-off workflow overrides (e.g. covering for an absent approver) without changing the permanent setup

# Slide 3 — Live Demo: Creating a Travel Request

**Steps to show:**
1. Log in as an employee
2. Start a new Advance Request → select **Travel** as the Advance Type
3. Fill in requester details, purpose, and payment method (EcoCash or Bank)
4. Add travel line item(s): date, district/destination, number of days/meals
   - Amount auto-calculates based on staff tier rate
5. Review the auto-computed Total and "Amount in Words"
6. Submit the request
7. Show resulting status: **SUBMITTED**, with the tracking stepper/stages visible
8. (Optional) Switch to the next approver's login → show it landing in their **Inbox**

**Talking point:** from this point the request moves automatically through the configured approval chain with no manual handoffs.
